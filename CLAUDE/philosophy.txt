## 1. Tactic/Init.lean
════════════════════════════════════════════════════════════════

### 核心
`aesop_cat`：依序嘗試 `apply_rfl` → `aesop (CategoryTheory 規則集)` → `simp`。

### Aha moment
所有範疇公理（`id_comp`、`comp_id`、`assoc`）的預設證明都是 `by aesop_cat`。
絕大多數公理是「定義上顯然」的，aesop_cat 讓樣板消失。

### 數學直覺
aesop_cat 是「範疇自動機」——用來處理那些對人類顯然、但 Lean 需要被告知的等式。

## 2. Basic.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Category`：obj, hom, id, comp；三條公理 id_comp / comp_id / assoc
- `Cᵒᵖ`：對偶範疇，hom 方向反轉，合成順序反轉
- `Whisker.right_cancel` / `left_cancel`：在等式兩側貼上同一個態射

### 重要屬性
```
attribute [simp] Category.assoc
```
assoc 方向：`(f ○ g) ○ h = f ○ (g ○ h)`（左→右）。
**simp 會將式子正規化為右結合形式。**
要得到左結合，需用 `rw [← Category.assoc]`。

### Aha moment
`Cᵒᵖ` 的定義極簡：obj 不變，hom 互換端點，comp 順序翻轉。
對偶原則（duality）在 Lean 中是一個「真正的 abbrev」，不需要任何新證明。

### 數學直覺
Whisker 就是「在等式兩側乘以同一個態射」——這是範疇論中最基本的推導步驟。

## 3. Functor/Basic.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Functor C D`：obj 映射 + map 映射；公理 map_id / map_comp
- `Cat`：範疇的範疇，物件=範疇，態射=函子，合成用函數合成 `∘`
- `Fᵒᵖ : Cᵒᵖ ⥤ Dᵒᵖ`：對偶函子（map 不變，但合成順序反轉）

### 重要屬性
```
attribute [simp, grind =, grind _=_] Functor.map_id Functor.map_comp
```
`map_comp : F[g ○ f] = F[g] ○ F[f]`

### Aha moment — Cat.comp 展開問題
`Cat` 中函子合成用的是 Lean 的 `Function.comp`（`∘`），所以：
```
(Cat.comp G F)[f]  ≡  G.map ∘ F.map  ≡  G[F[f]]
```
但這個等式**不是定義相等**，需要 `Cat.eq_1, Function.comp_apply` 才能展開。
這是 `simp only` 組合需要包含這兩個引理的根本原因。
單用 `id_eq, Category.assoc` 無法展開 `(Cat.comp F G)[f]`。

### 數學直覺
函子 = 保持結構的地圖。`Cat` 是「所有範疇住在裡面的宇宙」。

## 4. NatTrans/Basic.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `NatTrans F G`：`app X : F[X] ⟶ G[X]` + `naturality : α·Y ○ F[f] = G[f] ○ α·X`
- `α·X` 記號：自然變換在物件 X 的分量
- `αᵒᵖ : Gᵒᵖ ⇒ Fᵒᵖ`：對偶自然變換（方向反轉）

### 輔助引理
- `naturality_assoc`：`α·Y ○ F[f] ○ h = G[f] ○ α·X ○ h`（帶尾部態射版本）
- `functor_naturality`：`F[α·Y] ○ F[G[f]] = F[H[f]] ○ F[α·X]`（函子作用後的自然性）

### Aha moment
自然性條件 `α·Y ○ F[f] = G[f] ○ α·X` 是「正方形交換」。
輔助引理的作用是：讓 `grind` 能處理帶有額外態射尾巴的版本。

### 數學直覺
自然變換 = 「族映射的相容性」。每個物件有一個分量，所有分量在函子作用下相容。

## 5. Structure/FunctorCat.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `⟦C, D⟧`：函子範疇，物件=函子，態射=自然變換
- 垂直合成：`(β ○ α)·X = β·X ○ α·X`（逐點合成）
- `eval : ⟦C, D⟧ × C ⥤ D`：求值函子，`eval[(F, X)] = F[X]`

### Aha moment
`eval[(α, f)] = α·q.2 ○ p.1[m.2]`——結合了自然變換分量與函子作用。
這正是函子範疇中態射作用的「標準定義」。

### 數學直覺
函子範疇讓「函子之間的關係」成為一等公民。垂直合成 = 自然變換逐點合成。

## 6. Structure/ProductCat.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `C × D`：積範疇，物件與態射均為序對，合成逐分量
- `ProductCat.swap : C × D ≅[Cat] D × C`
- `ProductCat.assoc : (C × D) × E ≅[Cat] C × (D × E)`
- `Category.hom.Prod (f, g)`：態射序對

### Aha moment
swap 和 assoc 的 hom 與 inv 完全相同（只是 component 對調），所以
`hom_inv_id` 和 `inv_hom_id` 自動成立。

### 數學直覺
範疇的笛卡兒積，其結構與集合笛卡兒積類比。

## 7. Functor/BiFunctor.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `F[X, Y]`、`F[f, g]`：雙函子符號
- `fix_left F X : D ⥤ E`：固定左引數
- `fix_right F Y : C ⥤ E`：固定右引數
- `interchange`：`F[𝟙, g] ○ F[f, 𝟙] = F[f, g]`（交換律）

### Aha moment
交換律 `interchange`：雙函子可以「分開作用再合併」。
`F[f, g] = F[𝟙, g] ○ F[f, 𝟙] = F[f, 𝟙] ○ F[𝟙, g]`（兩個方向都成立）。
這是雙函子的核心計算工具。

### 數學直覺
雙函子在兩個方向都是函子，且兩個方向的作用「互相獨立」。

## 8. Functor/Currying.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `curry : ⟦C × D, E⟧ ⥤ ⟦C, ⟦D, E⟧⟧`
- `uncurry : ⟦C, ⟦D, E⟧⟧ ⥤ ⟦C × D, E⟧`
- `uncurry_curry_iso`：`uncurry(curry F) ≅ F`（分量為 `𝟙`，定義等同）
- `curry_uncurry_iso`：`curry(uncurry G) ≅ G`（需要 `map_id` 消去額外恆等態射）

### Aha moment
`uncurry_curry_iso` 的分量是 `𝟙` 因為
`uncurry[curry[F]][p] = F[p.1][p.2]` 與 `F[p]` 定義相等
（當 p = (X, Y) 時展開一致）——恆等自然同構的分量由定義等同見證。

### 數學直覺
Currying = 指數律。`(C × D → E) ≅ (C → (D → E))`——函子版本的柯里化同構。

## 9. Functor/Const.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Diagonal (Δ) : C ⥤ ⟦J, C⟧`：對角函子（常數函子族）
- `Δ[X]`：將 J 的所有物件送到 X，所有態射送到 `𝟙 X`
- `Δ[f]`：每個分量均為 f 的自然變換

### 數學直覺
對角函子是極限伴隨 `lim ⊣ Δ` 的右邊。
「常數函子」= 忽略 J 中的所有結構，只記住 C 中的目標物件。


════════════════════════════════════════════════════════════════
## 10. NatTrans/Iso.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `NatIso F G = F ≅[⟦C, D⟧] G`（函子範疇中的同構）
- `NatIso.ofComponents`：從逐點同構建構自然同構
- `α·X`、`α⁻¹·X`：正逆方向的分量
- `inv_hom_id_app`：`α⁻¹·X ○ α·X = 𝟙`
- `hom_inv_id_app`：`α·X ○ α⁻¹·X = 𝟙`

### Aha moment
`ofComponents` 中 `inv` 的自然性：從 `α.hom` 的自然性導出。
關鍵計算：
```
α⁻¹·Y ○ α·Y ○ F[f] ○ α⁻¹·X = F[f] ○ α⁻¹·X
```
使用左右消去律（inv_hom_id + simp），然後 `grind` 完成。

### 數學直覺
自然同構 = 逐點都是同構的自然變換。
`ofComponents` 的存在意義：不需要同時提供 inv 的自然性（可從 hom 的自然性導出）。


════════════════════════════════════════════════════════════════
## 11. NatTrans/Horizontal.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `β ◫ α : H ○ F ⇒ K ○ G`：水平合成
  分量：`(β ◫ α)·X = K[α·X] ○ β·F[X]`
- `Whisker.Functor_NatTrans`（H ◫ α）：函子右鬚積
- `Whisker.NatTrans_Functor`（β ◫ F）：函子左鬚積
- Godement 交換律：`(β₂ ○ β₁) ◫ (α₂ ○ α₁) = (β₂ ◫ α₂) ○ (β₁ ◫ α₁)`

### Aha moment
水平合成的分量公式 `K[α·X] ○ β·F[X]` 也等於 `β·G[X] ○ H[α·X]`
（由 β 的自然性可得）。選哪種形式取決於證明需要。
Godement 交換律：「先垂直再水平 = 先水平再垂直」——是 2-範疇結構的核心。

### 數學直覺
水平合成讓自然變換可以「並排」合成，形成 2-範疇結構。

## 12. Morphism/EpiMono.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `IsMono f`：右消去律（f ○ h = f ○ k → h = k）
- `IsEpi f`：左消去律（h ○ f = k ○ f → h = k）
- `IsSplitMono f`：存在左逆 `left_inv ○ f = 𝟙`（比 Mono 更強）
- `IsSplitEpi f`：存在右逆 `f ○ right_inv = 𝟙`（比 Epi 更強）

### 包含關係
SplitMono ⊇ Mono，SplitEpi ⊇ Epi
SplitMono 的左逆是 SplitEpi

### Aha moment
`IsSplitMono.IsMono`：要從左逆導出消去律，只需：
```
h = 𝟙 ○ h = (left_inv ○ f) ○ h = left_inv ○ (f ○ h) = left_inv ○ (f ○ k) = k
```

### 數學直覺
Mono ≈ 單射，Epi ≈ 滿射。Split 版本有「明確的截面」，
在 Types 中 Epi = SplitEpi（用 Classical.choice）。


════════════════════════════════════════════════════════════════
## 13. Morphism/Iso.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Iso X Y`：hom + inv + hom_inv_id + inv_hom_id
- `Iso.ext`：同構由正方向 hom 唯一決定
- `IsIso f`：態射的「可逆性」class，`f⁻¹` 記號
- `SplitMono_Epi_IsIso`：可裂單態射 + 滿態射 ⟹ 同構
- `SplitEpi_Mono_IsIso`：可裂滿態射 + 單態射 ⟹ 同構

### Aha moment
`Iso.ext`：同構的逆是唯一的，因為若 `i.hom = j.hom`，則：
```
i.inv = i.inv ○ i.hom ○ j.inv = j.inv
```
（用 inv_hom_id 消去中間）。

`SplitMono_Epi_IsIso`：有了左逆（split mono），再加上右消去（epi），就能導出雙側逆。
關鍵：`f ○ 𝟙 = 𝟙 ○ f`，代入左逆後用 epi 消去 f。

### 數學直覺
同構 = 可逆態射。ext 說明逆是唯一的（由正向態射決定）。
SplitMono + Epi = Iso：這是許多「對象同構」定理的基礎模式。

## 14. Structure/Types.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Types : Category`：物件 = Lean Type，態射 = 函數，合成 = `∘`
- `Hom : Cᵒᵖ × C ⥤ Types`：Hom 雙函子，`Hom[f, g] : h ↦ g ○ h ○ f.op`
- `Types.Mono_iff_Injective`：Mono ↔ 單射
- `Types.Epi_iff_Surjective`：Epi ↔ 滿射
- `Types.Bijection_to_Iso`：雙射 → 同構（用 Classical.choice 取逆）

### Aha moment
`Hom` 雙函子的 map：`map f h = f.2 ○ h ○ f.1.op`
- 左引數 `f.1 : Xᵒᵖ`（逆變方向）：右合成 `○ f.1.op`
- 右引數 `f.2`（協變方向）：左合成 `f.2 ○`

`NatIso.hom_inv_id_app_apply`：`α.hom·X (α.inv·X x) = x`（逐點版本）
——這是後續伴隨證明中最常用的 simp 引理之一。

### 數學直覺
Types 是範疇論的「具體模型」，所有抽象概念在這裡化為集合論概念。
Hom 雙函子統一了 Hom(X, –) 和 Hom(–, Y) 的協變/逆變行為。

## 15. Functor/FullyFaithful.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Functor.Full`：map 是滿射（任何 F[X]→F[Y] 都有原像）
- `Functor.Faithful`：map 是單射（F[f]=F[g] → f=g）
- `Functor.FullyFaithful`：map 是雙射
- `preimage`：用 `surjInv` 從 `F[X]→F[Y]` 取回 `X→Y`

### 重要引理
- `map_preimage_id`：`F[F.preimage f] = f`（全函子的關鍵性質）
- `preimage_map_id`：`F.preimage F[f] = f`（全忠實函子）

### Aha moment
`FullyFaithful` 的 `preimage` 用 `surjInv`（非建構性），所以需要 `noncomputable`。
`preimage_map_id` 的證明：`F[F.preimage F[f]] = F[f]`（由 map_preimage_id），
再用 Faithful 消去 F 得 `F.preimage F[f] = f`。

### 數學直覺
全忠實函子 = 「精確嵌入」。它保留所有態射資訊，
因此可以從像中反射回原範疇的結構。

## 16. Morphism/PreserveReflect.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Preserve.IsIso`：函子保持可逆態射（對所有函子成立）
- `Preserve.Iso`：函子將 `X ≅ Y` 映射到 `F[X] ≅ F[Y]`
- `Reflect.IsMono`：忠實函子反射 Mono
- `Reflect.IsIso`：全忠實函子反射同構（用 preimage 建構逆）

### Aha moment
`Reflect.IsIso`：`inv := F.preimage F[f]⁻¹`，
然後用 `F.map_injective` + `simp [F.map_preimage_id]` 驗證兩條等式。
關鍵：全忠實性提供了「在 F 的像中驗證等式就夠了」的能力。

### 數學直覺
保存 = 函子「主動地」傳遞結構。反射 = 忠實函子「被動地」從像恢復結構。

## 17. Yoneda.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `yoneda : C ⥤ ⟦Cᵒᵖ, Types⟧`：Yoneda 嵌入，`yoneda[X] = Hom[–, X]`
- `coyoneda : Cᵒᵖ ⥤ ⟦C, Types⟧`：餘 Yoneda 嵌入，`coyoneda[X] = Hom[X, –]`
- `yoneda.Principal`：`F[f] (α·X (𝟙 X)) = α·A f`（Yoneda 主引理）
- `yoneda.Equiv X F : (Hom[–, X] ⇒ F) ≅[Types] F[X]`（Yoneda 等價）
- `yoneda.FullyFaithful`：Yoneda 嵌入是全忠實的

### 重要引理
- `yoneda.Principal`：自然變換 `α : Hom[–, X] ⇒ F` 由 `α·X (𝟙 X) : F[X]` 唯一決定。
  證明：用 `Types.naturality_apply α f` 得 `α·A f = F[f] (α·X (𝟙 X))`。

### Aha moment — Yoneda 的核心洞見
自然變換 `Hom[–, X] ⇒ F` 中，每個 `α·A f`（其中 `f : A ⟶ X`）都等於
`F[f]` 作用於 `α·X (𝟙 X)`。
也就是說，`α` 完全由「它在恆等態射處的值」決定——「恆等態射是萬能探針」。

`yoneda.FullyFaithful` 的完全性：每個 `α : Hom[–, X] ⇒ Hom[–, Y]` 形如 `yoneda[α·X (𝟙 X)]`。
用 `ext Z g` + `Types.naturality_apply α g (𝟙 X)` + `simp_all` 完成。

### 數學直覺
「物件由它與所有其他物件的關係決定。」
Yoneda 引理將抽象的自然變換空間壓縮成一個點（`F[X]` 的一個元素）。
這是整個函子論的基石。

## 18. Functor/Hom.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Hom.preserve_iso_left`：`X ≅ Y → Hom[X, –] ≅ Hom[Y, –]`
- `Hom.preserve_iso_right`：`X ≅ Y → Hom[–, X] ≅ Hom[–, Y]`
- `Hom.reflect_iso_left`：`Hom[X, –] ≅ Hom[Y, –] → X ≅ Y`（米田反射）
- `Hom.reflect_iso_right`：`Hom[–, X] ≅ Hom[–, Y] → X ≅ Y`
- `Hom.preserve_natiso_right`：`F ≅ G → Hom[–, F–] ≅ Hom[–, G–]`
- `Hom.reflect_natiso_right`：`Hom[–, F–] ≅ Hom[–, G–] → F ≅ G`

### Aha moment
`Hom.reflect_iso_left`：給定 `iso : Hom[X, –] ≅ Hom[Y, –]`，
- `hom := iso⁻¹·Y (𝟙 Y)`（透過 Y 的恆等態射取值）
- `inv := iso·X (𝟙 X)`（透過 X 的恆等態射取值）

驗證 `inv ○ hom = 𝟙`：
```lean
let p := congrFun (iso.hom.naturality (iso·X (𝟙 X))) (iso⁻¹·Y (𝟙 Y))
```
自然性方程讓兩個「應用」可以互相消去。

這正是 Yoneda 全忠實性的幾何意義：Hom 函子的自然同構完全捕捉了物件同構。

### 數學直覺
這個檔案是「米田反射」的計算展現：Hom 函子不只保持同構，還能「反射」回來。
`reflect_natiso_right` 是「函子的自然同構等價於函子的同構」的精確表述。

## 19. UniversalProperty.lean
════════════════════════════════════════════════════════════════

### 核心定義
- `Universal G X A = Hom[A, –] ≅ Hom[X, G–]`：泛性質（X 在 G 下的泛物件為 A）
- `coUniversal F A X = Hom[Fᵒᵖ–, A] ≅ Hom[–, X]`：餘泛性質
- `Universal.morphism`：泛態射 `u·A (𝟙 A) : X ⟶ G[A]`
- `Universal.factorization`：`f = G[u⁻¹·B f] ○ u.morphism`（唯一分解）
- `IsUniversal u`：命題性泛態射條件（存在唯一分解）
- `Universal.uniqueUpToIso`：泛物件在同構意義下唯一

### 重要定理
- `Universal.Property`：泛性質結構 → IsUniversal
- `IsUniversal.Universal`：IsUniversal → 泛性質結構（`noncomputable`）

### Aha moment — factorization 的核心
`Universal.factorization` 的證明：
```lean
simpa using congrFun (u.hom.naturality (u⁻¹·B f)) (𝟙 A)
```
自然性方程 `u.hom.naturality h` 說 `u·B (h ○ –) = G[h] ○ u·A (–)`。
代入 `h = u⁻¹·B f` 並計算 `(𝟙 A)` 處的值，就得到分解式！

`Universal.Property` 中唯一性的證明：
```lean
fun f' q => by
  let p := congrFun (u.hom.naturality f') (𝟙 A)
  simpa [←q, ←NatIso.eq_symm_apply] using p
```
用函子自然性 + 同構的 eq_symm_apply 完成。

### 數學直覺
泛性質 = 可表示性。`Hom[A, –] ≅ Hom[X, G–]` 說
「A 的射出空間就是 X 透過 G 看到的空間」。
uniqueUpToIso：米田嵌入的全忠實性保證了泛物件在同構意義下唯一。

## 20. Adjunction/Basic.lean
════════════════════════════════════════════════════════════════

### 核心定義
```
Adjunction F G = Hom[Fᵒᵖ–, –] ≅ Hom[–, G–]
```
四種等價表述：
1. **Adjunction**（自然同構版）：最簡潔
2. **HomEquiv**：逐個 Hom 集的同構 + 兩條自然性條件
3. **HomMate**：Hom 集同構 + mate 條件
   `k ○ f = g ○ F[h] ↔ G[k] ○ φ(f) = φ(g) ○ h`
4. **Units**：η（單位）+ ε（餘單位）+ 兩條三角恆等式

### 重要記號
- `φ♯f`（sharp）：`F[X]→A` 轉置為 `X→G[A]`
- `φ♭f`（flat）：`X→G[A]` 轉置為 `F[X]→A`

### 關鍵引理與 Aha moments

**`HomEquiv.HomMate.mate` 逆方向**（從 φ-等式恢復原等式）：
```lean
fun p => by
  let p := congrArg (φ.equiv X _).inv p
  let q := congrArg (φ.equiv X _).inv (φ.naturality_right f k)
  simp [-naturality_right] at p q
  simp_all
```
Aha：對兩端都施加 `equiv.inv`，讓 simp 消去 hom_inv round-trip。
`-naturality_right` 防止 simp 重新展開剛剛消去的項。

**`Units.left_triangle_hom`**：`f ○ ε·F[X] ○ F[η·X] = f`
三角恆等式存儲為右結合形式；需要先 `simp [Category.assoc]` 正規化後 `exact` 才能匹配。

**`Units.Adjunction inv_hom_id`** 中 naturality 展開問題：
```lean
have h := u.ε.naturality f
simp only [Cat.eq_1, Function.comp_apply, id_eq] at h
```
Aha：naturality 含有 `(Cat.comp F G)[f]`，
必須用 `Cat.eq_1, Function.comp_apply` 展開為 `F[G[f]]`，
而非 `id_eq, Category.assoc`（後者無法展開 Cat.comp）。

**`Units.Adjunction hom_inv_id`** 中用 `erw`：
```lean
erw [← u.η.naturality f]
```
用 `erw` 因為 `rw` 無法匹配 `Cat.comp` 的底層形式。

### 四種表述的轉換環
```
Adjunction ↔ HomEquiv ↔ HomMate
    ↑                      ↑
    └─── Units ────────────┘
```
每個轉換都有對應的 `def`/`abbrev`。

### 泛性質與伴隨的聯繫

**Universal.Adjunction**：給定每個 X 的泛物件族，構造 `F : C ⥤ D` 使得 `F ⊣ G`。
函子 F 在態射的作用：用 `coyoneda.Equiv` 從自然變換恢復態射。

**Adjunction.Universal**：每個伴隨對每個 X 都誘導泛性質
（`F[X]` 是 `X` 相對 `G` 的泛物件）。

### 數學直覺
伴隨 = 「全局的泛性質族」。
- 給定伴隨，每個 X 都有一個泛物件（Adjunction.Universal）
- 有了所有 X 的泛物件族，可以重建伴隨（Universal.Adjunction）

**伴隨 ≡ 每個物件都有泛性質**

`F ⊣ G` 說「F 是 G 的最優逼近」——每個 `X → G[A]` 都唯一穿過
`X → G[F[X]]`（泛態射）分解到 `F[X] → A`。
Sharp/Flat 轉置 = 「在兩種觀點之間翻譯」的操作。
